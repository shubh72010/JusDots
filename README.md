## 🚀 Getting Started

### Prerequisites

- Modern web browser (Chrome, Firefox, Safari, Edge)
- Basic understanding of HTML, CSS, and web design

### Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd JusDotsWebsiteV2
   ```

2. **Open in browser**
   - Simply open `index.html` in your preferred web browser
   - Or use a local development server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx http-server
   ```

3. **View in browser**
   - Navigate to `http://localhost:8000`

## 🎨 Design System

### Typography

- **Reference Sans** - Primary font family for body text
- **Reference Display** - Display font for headings and highlights
- Both fonts support weights from 100-900

### Color Scheme

- **Primary** - Pure black (`#000000`)
- **Accents** - Subtle gradients and overlays for depth
- **Theme** - Dark color scheme optimized for reduced eye strain

### Spacing System

The design uses fluid, responsive spacing:
- Gutters: `clamp(36px, 4.177vw, 96px)` to `clamp(36px, 4.04vw, 96px)`
- Headers: `clamp(20px, 2.264vh, 30px)`
- Typography: Carefully balanced line heights and gaps
